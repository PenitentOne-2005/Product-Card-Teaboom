# Карточка товара — «Ананасовый улун»

Реализована верхняя часть карточки товара «Ананасовый улун» для интернет-магазина [Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun).

## Реализовано

* адаптивная карточка товара;
* изображение товара;
* название и категория;
* краткое описание;
* выбор фасовки;
* динамическое изменение:

  * актуальной цены;
  * старой цены;
  * артикула;
  * выбранного состояния фасовки;
* кнопка «В корзину» с hover-состоянием;
* семантическая HTML-разметка;
* клавиатурная навигация и доступные состояния фокуса;
* поддержка `prefers-reduced-motion`;
* визуально скрытая область для объявления изменений выбранной фасовки скринридерам.

## Технологии

* HTML5
* CSS3
* JavaScript
* Flexbox
* CSS Media Queries

Без использования Bootstrap и готовых шаблонов.

## Адаптивность

Интерфейс протестирован для следующих размеров:

* 375 px — mobile;
* 768 px — tablet;
* 1440 px — desktop.

На мобильных устройствах элементы карточки располагаются в одну колонку, на больших экранах — в две колонки.

## Запуск

Проект не требует установки зависимостей и сборки.

Для запуска используется Live Server в Visual Studio Code:

1. Открыть проект в Visual Studio Code.
2. Установить расширение Live Server, если оно ещё не установлено.
3. Открыть `index.html`.
4. Нажать **Go Live** в нижней панели Visual Studio Code.
